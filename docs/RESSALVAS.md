# Registro de ressalvas

Ressalvas de dados e de método acumuladas ao longo do projeto. Os resultados no README citam os códigos das ressalvas que se aplicam a eles. Uma ressalva só sai da lista "ativa" com evidência registrada.

Legenda de severidade: **alta** (pode mudar a conclusão), **média** (muda a precisão ou o alcance), **baixa** (registro).
